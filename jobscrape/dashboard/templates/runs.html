Run the full pipeline
One button, the whole process: discover every board, validate every unchecked one, fetch every currently open posting from the last 2 months from every source (including Apify), then collapse reposts and cross-source duplicates. No cap on which boards get checked — this is the complete, deduplicated archive for that window in a single run, at the cost of being the slowest option here.

Fetch jobs in a date range

ATS boards and public job APIs — not Apify (see the Apify card below). Only postings dated within this range are collected. Leave both blank to fetch everything. Cross-source dedupes and refreshes stats afterward, in the same run.

Fetch Apify jobs in a date range

Indeed/LinkedIn postings via Apify. Only postings dated within this range are kept — leave both blank to keep everything from the last 3 successful actor runs. Cross-source dedupes and refreshes stats afterward, in the same run.

Fetch JobRight jobs in a date range

Sweeps a fixed set of 18 software roles (Backend, Full Stack, Python, Java, C/C++, .Net, Golang, Data, ML, AI, LLM, Frontend, React, Android, iOS, Flutter, DevOps, SRE) on JobRight.ai, remote postings only. Only postings dated within this range are kept — leave both blank to keep everything scraped. Needs the jobright extra, a real Chrome install, and JOBRIGHT_EMAIL/JOBRIGHT_PASSWORD set in Settings. Opens a real Chrome window (a virtual display in Docker) and logs into your JobRight account — this can take 20–45+ minutes.
